# OWASP Top 10: 2021 to 2025

Source: OWASP Top 10:2025 (https://owasp.org/Top10/2025/). Check the project site for
the authoritative text and any later revisions.

| 2025 | 2021 equivalent | What changed |
| --- | --- | --- |
| A01 Broken Access Control | A01 Broken Access Control, A10 SSRF | SSRF is folded into access control |
| A02 Security Misconfiguration | A05 Security Misconfiguration | moved up |
| A03 Software Supply Chain Failures | A06 Vulnerable and Outdated Components | widened to the whole supply chain: dependencies, build systems, distribution |
| A04 Cryptographic Failures | A02 Cryptographic Failures | moved down |
| A05 Injection | A03 Injection | includes XSS as before |
| A06 Insecure Design | A04 Insecure Design | moved down |
| A07 Authentication Failures | A07 Identification and Authentication Failures | renamed |
| A08 Software or Data Integrity Failures | A08 Software and Data Integrity Failures | renamed slightly |
| A09 Security Logging and Alerting Failures | A09 Security Logging and Monitoring Failures | emphasis on alerting |
| A10 Mishandling of Exceptional Conditions | (new) | error handling, failing open, unhandled edge cases |
